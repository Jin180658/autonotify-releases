# AutoNotify 0.1.18

The customer phone field is now optional. Add or edit a customer with the field blank, or save a Malaysian, Singaporean or other international number in local or international format. AutoNotify preserves country codes, leading zeros, separators and common extensions.

Examples include `011-2345 6789`, `(03) 2345 6789`, `+65 8123 4567` and `6234 5678 ext. 12`.

## Update

Open **Settings → Software updates** and select the available update. If the old copy cannot start, download **AutoNotify-Setup-0.1.18.exe** below and install under the same Windows account using the existing installation folder. The installer includes the 0.1.17 Windows startup repair and retains existing customer records and settings.

The phone change passed 177 unit tests, lint, the translation audit and a production build.
